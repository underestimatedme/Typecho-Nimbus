# Nimbus 用户手册

## 安装

1. 把 `Nimbus` 目录上传到 Typecho 的 `usr/themes/`。
2. 后台「控制台 → 外观」启用。
3. 「设置外观」中配置。所有选项都有默认值，留空即用默认。

## 常见问题

**切换皮肤后颜色没变？** 浏览器记住了上次选择（localStorage `nimbus-theme`）。清掉或在地址后加 `?nimbus_theme=sky`。

**首页没有置顶轮播？** 「首页 → 置顶文章」需填写文章 cid（编辑文章时地址栏里的数字），多个用逗号分隔；只显示已发布且无密码的文章。

**文章卡片没有图？** 顺序为：自定义字段 `thumb` → 正文首图 → 「默认缩略图池」→ 主题内置渐变图。

**目录不显示？** 需要文章至少有两个 `h2/h3/h4` 标题，且未在文章编辑页勾选「隐藏目录」。

**无刷新切换和某些统计脚本冲突？** 在「高级」里关闭「无刷新页面切换」。

**想用自己的字体？** 「外观 → 字体方案」选自定义，填入字体 CSS 链接与字体名。

**评论提交后回到文章页但没有新评论？** 检查 Typecho「设置 → 评论」里是否开启了审核；主题已内嵌反垃圾 token，无需额外设置。

**GitHub 登录按钮没出现？** 在 NimbusKit 设置里同时填写 Client ID 与 Client Secret；GitHub OAuth App 的回调地址要和设置页提示的完全一致。

**IP 属地不显示？** 需要把 ip2region 的 `ip2region.xdb` 放到 `usr/plugins/NimbusKit/data/`，见该目录的 README。

**升级后收藏夹 / 项目 / GitHub 登录不可用？** 到「控制台 → 插件」把 NimbusKit 禁用再启用一次，插件会建新表、注册新钩子，设置自动保留。

**音乐页没有频谱跳动？** 跨域音频（如网易云外链）出于浏览器安全限制无法读取频谱，页面会改用模拟动画；把音频放在本站即可显示真实频谱。

**回复可见的内容评论后还看不到？** 评论需要通过审核；访客需在同一浏览器、使用评论时填写的邮箱。

## 性能建议

- 把 `assets` 目录同步到 CDN，并在「高级 → 静态资源 CDN 前缀」填入地址。
- Hero 背景图建议 1920×1080 以内、WebP 格式。
- 动效强度选「克制」可关闭装饰性动画，低端设备更流畅。
- 统计看板每次访问会统计全部文章字数；文章上千篇时建议配合页面缓存插件使用。
