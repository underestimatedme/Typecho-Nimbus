# Nimbus 路线图

## 第 1 期：主题本体（已完成，v1.0.0）

三套皮肤、首页 / 文章 / 评论 / 归档 / 友链 / 关于 / 404、侧栏小部件、无刷新切换、后台配置页；之后追加自适应版面与沉浸式文章布局。

## 第 2 期：NimbusKit 插件（已完成，v1.1.0）

浏览量、点赞、即时搜索、AJAX 评论、邮件通知、说说、友链管理、相册、Sitemap。SQLite / MySQL / PostgreSQL 实测。

## 第 3 期：增强功能（待开始）

参考对象：[栖光集](https://blog.tianevan.com)（Next.js 自研博客）中适合 Typecho 的部分，加上原计划的增强项。

| 功能 | 归属 | 说明 |
| --- | --- | --- |
| 收藏夹（网址导航） | 插件 + 主题模板 | 分组管理常用站点与工具，图标、简介、分组计数 |
| 项目展示 | 插件 + 主题模板 | 项目名称、简介、技术栈标签、链接、封面 |
| 留言板 | 主题模板 | 独立页 + 评论，留言墙式排版 |
| GitHub 登录留言 | 插件 | GitHub OAuth 登录后留言 / 评论，自动填写昵称、头像、主页 |
| 音乐页与播放器 | 插件 + 主题 | 歌单页与全站悬浮播放器，支持自定义歌单与常见音乐平台歌单 |
| Live2D 看板娘 | 主题 | 纯前端，可开关、可换模型，移动端默认关闭 |
| 时间线页 | 主题模板 | 横向「时光河流」式文章时间线 |
| 短代码 | 主题 | 提示框、折叠块、标签页、按钮、视频、B 站嵌入、GitHub 卡片、回复可见 |
| 分享海报 | 主题 | 文章生成分享图 |
| 站点统计看板 | 插件 + 主题 | 浏览量、热门、评论趋势图表 |
| 评论者 IP 属地 | 插件 | 可选，需放入离线 IP 库 |
| 中英双语界面 | 主题 + 插件 | 前台与后台文案可切换 |
| 配置导入导出 | 主题 | 主题设置备份与迁移 |
| 赛博朋克特效增强 | 主题 | 更多霓虹与故障动效 |

### 明确不做

- **聊天室**：需要常驻的实时连接服务，不适合 Typecho（PHP 按请求运行）的架构，已确定不做。
