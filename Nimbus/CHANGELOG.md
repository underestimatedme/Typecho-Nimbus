# 更新日志

## 1.2.0

主题：

- 文章列表分页方式由后台「首页 → 分页方式」决定：分页（页码）/ 滚动加载 / 加载更多按钮；可选开启「访客可切换分页方式」（默认关闭）。
- 统计页可交互：热力图点击看当天文章、分类分布可点击、热门文章「查看全部」。
- 系列教程：分类可设为教程，首页展示教程卡片与学习进度，分类页变为课程目录，文章页显示章节导航与上一章 / 下一章。
- Hero 背景支持「每日必应」：每天自动换成必应当日壁纸，服务端每天取一次并缓存（中文站走 cn.bing.com），封面右下角显示图片说明与版权；取不到时回落到自定义背景。
- 全新「杂志」首页（默认）：极光封面、3D 文章卡片堆、分类滚动条、Bento 精选网格、通栏文章网格；可在「首页 → 首页风格」切回经典。
- 全新「杂志」文章页（默认）：封面舞台、悬浮正文卡片、左目录、右操作栏、编号小标题、引言式引用、大图上一篇 / 下一篇；已保存过「文章页布局」的站点需在设置里改为「杂志」。
- 时间线改为纵向：年份吸顶、左右交错、中轴随滚动点亮。
- 赛博朋克字符雨改为真实代码：每列从一行 Python / Go / Rust 代码里逐字落下（竖着读就是代码），关键字高亮；可在「外观 → 字符雨代码」选择语言（之前是日文片假名）。
- 加载速度：样式合并为单文件、脚本模块预加载，首页首屏从数秒降到 0.2 秒内（本地测试站）。

- 新页面模板：留言板（卡片墙）、横向时间线、音乐、统计看板、收藏夹、项目展示。
- 短代码：提示框、折叠块、标签页、按钮、视频、B 站、GitHub 卡片、回复可见（隐藏内容不进 RSS、摘要与搜索）。
- 全站悬浮音乐播放器与音乐页：黑胶、频谱、LRC 歌词，无刷新切换页面不中断。
- 分享海报：Canvas 绘制，内置自写二维码编码器，可下载 PNG。
- 前台中英双语，可跟随浏览器。
- 赛博朋克特效：字符雨、标题故障、霓虹描边、鼠标拖尾、副标题解码。
- Live2D 看板娘（可选，从 CDN 加载）。
- 后台设置导入 / 导出。
- 导航放不下时自动收进「更多」。
- 修复：窄屏导航菜单误显示；多选设置项首次保存丢失；`[button]` 短代码按钮跑出正文栏。
- 文章日期、时间线、统计按站点时区显示（之前用的是服务器时区）。
- 统计看板字数与时间线结果缓存，文章多的站点不再每次全量读取。
- 启用主题时设置保存到正确的 `theme:Nimbus` 行（之前会写到上一个主题名下）。

安全：

- 回复可见不再信任可伪造的邮箱 cookie：装 NimbusKit 时只认本浏览器提交过且已通过的评论（签名 cookie）；未装时额外校验评论 IP。登录用户中只有本文作者与「贡献者」以上可直接查看。升级后，之前评论过的访客需要再评论一次才能解锁。
- Typecho 自带搜索不再能通过回复可见里的文字搜到文章（需 NimbusKit）。
- 被 `<!--more-->` 截断的未闭合 `[hide]` 不再出现在摘要和 RSS 中。
- GitHub 登录：显示名含括号等字符也能评论；显示名与本站注册用户重名时自动加上 `@login`，防止冒充站长。

NimbusKit 1.1.0：

- 收藏夹、项目管理（新表 `nimbus_bookmarks`、`nimbus_projects`）。
- GitHub 登录评论：OAuth、签名身份 cookie、可选「仅 GitHub 用户可评论」。
- 评论者 IP 属地（自写 ip2region xdb 读取器，数据文件自行下载）。
- 每日浏览量（新表 `nimbus_daily`），供统计看板绘制趋势。
- 前台提示跟随主题语言。

升级：覆盖主题与插件目录后，到「控制台 → 插件」**禁用再启用一次** NimbusKit，以创建新表并注册新钩子；插件设置会自动保留。

## 1.1.0

- 配套插件 NimbusKit 1.0：浏览量、点赞、即时搜索、AJAX 评论、邮件通知、说说、友链管理、相册、Sitemap。
- 新增「说说」「相册」页面模板；友链页读取插件数据；灯箱按图组浏览。
- 修复：归档 / 友链 / 关于模板缺少 `@package custom`，后台模板下拉框里选不到。
- NimbusKit 通过 SQLite、MySQL 9.3、PostgreSQL 17 实测（`tests/multi-db.sh`）。

- 自适应版面：内容宽度随屏幕放大，最宽 1760 像素；后台可选自适应 / 宽屏 / 标准。
- 文章页沉浸布局：有头图时通栏大图标题、导航透明叠加；超宽屏「目录｜正文｜侧栏」三栏；正文易读行宽，媒体铺满正文列。后台可切回经典布局。
- 首页网格列数随宽度自动增加，卡片与轮播高度随屏幕放大。

- 九个侧栏小部件。
- 无刷新页面切换、搜索弹窗、悬浮导航、移动端抽屉。
- 后台分组配置页。
